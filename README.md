# Dynamic Island Minimalistic Music Widget для Windows 10/11

Изысканный плавающий музыкальный виджет для Windows в стиле **Minimalistic Motion Design** (Dynamic Island / Frosted Glass / Glassmorphism) с плавной органичной анимацией и глубокой кастомизацией.

---

## ✨ Ключевые возможности

- 🎧 **Универсальная интеграция с плеерами**:
  - **Spotify** (десктопное приложение и веб-плеер)
  - **Apple Music** (нативное приложение для Windows и веб)
  - **SoundCloud** (через Chrome, Microsoft Edge, Firefox, Brave, Opera)
  - **YouTube Music / YouTube**
  - **Яндекс Музыка, VK Музыка, Deezer, Tidal, Foobar2000, AIMP, VLC** и любые другие плееры, поддерживающие Windows Media Control (GSMTC).
- 🌊 **Minimalistic Motion Design**:
  - Плавный морфинг между компактным режимом капсулы (Pill) и развёрнутой карточкой трека (Expanded Card).
  - Настраиваемые кинематографические кривые сглаживания (OutCubic, OutBack spring bounce, InOutQuad).
  - Анимированный звуковой эквалайзер/визуализатор с поддержкой 3 стилей: *Жидкие полосы (Liquid Bars)*, *Плавная волна (Fluid Wave)* и *Ритмичные точки (Dots)*.
  - Динамическое извлечение акцентного цвета прямо из обложки трека и мягкое неоновое свечение (Ambient Glow).
  - Плавная бегущая строка (Marquee) для длинных названий треков и авторов с паузами на краях.
- 🎛️ **Глубокая кастомизация (GUI Настройки)**:
  - **Внешний вид**: Быстрые пресеты (*Тёмное стекло*, *OLED Black*, *Кибернеон*, *Светлый стиль*), регулировка прозрачности (30%–100%), скругления углов (12px–32px), масштаба (80%–140%), выбор собственного акцентного цвета.
  - **Расположение**: Вверху по центру (классический Dynamic Island), вверху справа/слева, внизу экрана или свободное перемещение (Free drag-and-drop).
  - **Анимации**: Настройка скорости переходов (180ms – 500ms), чувствительности визуализатора.
  - **Поведение**: Разворачивание при наведении курсора, переключение по клику, режим «Поверх всех окон», перемотка трека колёсиком мыши.
- 🖱️ **Интерактивное управление**:
  - Кнопки воспроизведения: Предыдущий трек, Play / Pause с микроанимацией, Следующий трек.
  - Интерактивный прогресс-бар: клик и перетаскивание (scrubbing) для моментальной перемотки.
  - Колёсико мыши над виджетом: быстрая перемотка назад/вперёд на ±5 секунд.
  - Правый клик по виджету: контекстное меню для быстрой смены позиции, режима поверх окон и перехода в настройки.
  - Иконка в системном трее (возле часов) с возможностью скрыть/показать виджет и текущим статусом трека.

## 🚀 Запуск

### Быстрый запуск
Просто запустите файл:
```cmd
run.bat
```
Или для фонового запуска без окна консоли:
```cmd
run_silent.vbs
```

### Запуск через Python
```bash
pip install -r requirements.txt
python main.py
```

## 📂 Структура проекта

```
d:\Dynami Island\
├── main.py                  # Точка входа, трей и запуск приложения
├── requirements.txt         # Список зависимостей
├── run.bat                  # Пакетный файл запуска

│   ├── config_manager.py    # Менеджер настроек (JSON) с сигналами живого обновления
│   ├── media_manager.py     # Асинхронный движок Windows Media (GSMTC) + управление

└── ui/
    ├── widget.py            # Главный плавающий виджет с анимацией морфинга
    ├── settings_dialog.py   # Современное окно настроек с вкладками и слайдерами
    ├── visualizer.py        # Анимированный звуковой эквалайзер (60 FPS)
    ├── marquee_label.py     # Плавная бегущая строка для длинных названий
    ├── progress_bar.py      # Интерактивный скраббер/прогресс-бар с таймингами
    └── controls.py          # Векторные кнопки воспроизведения с эффектом нажатия
```

## ⚙️ Управление и горячие действия

| Действие | Результат |
|---|---|
| **Наведение курсора** | Автоматически плавно разворачивает виджет (настраивается) |
| **Отвод курсора** | Сворачивает виджет обратно в компактную капсулу |
| **Левый клик по виджету** | Переключение Компактный / Развёрнутый вид |
| **Колёсико мыши над виджетом** | Перемотка трека на ±5 секунд |
| **Правый клик по виджету** | Контекстное меню (Позиция, Настройки, Закрыть) |
| **Клик по трею (возле часов)** | Скрыть / Показать виджет |
| **Клик по шестерёнке / «Настройки»** | Открывает панель кастомизации с живым предпросмотром |
